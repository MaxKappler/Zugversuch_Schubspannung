Kräfte auf schräge Flächen: Das Schnittprinzip

Aus einer Normalspannung kann lokal eine Schubspannung werden

Zug-Druck-Stab mit geneigter Ebene

Visuelle Darstellung der Spannungsvektoren an der gedrehten Ebene $ arphi$.

$\sigma_0$ (Angelegt)
$\sigma_ arphi$ (Normalspannung)
$ au_ arphi$ (Schubspannung)
30° (0.52 rad)

Spannungsverlauf in Abhängigkeit von $ arphi$

Gleichungen der rotierten Ebene

Schnittfläche: $A_ arphi = rac{A_0}{\cos arphi}$
Normalspannung: $\sigma_ arphi = rac{F_\perp}{A_ arphi} = \sigma_0 \cos^2 arphi$
Schubspannung: $ au_ arphi = rac{F_\parallel}{A_ arphi} = \sigma_0 \sin arphi \cos arphi = rac{\sigma_0}{2} \sin(2 arphi)$
Max. Schubspannung bei $ arphi = 45^\circ$: $ au_{\max} = rac{\sigma_0}{2}$
